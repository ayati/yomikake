ブラウザ翻訳がどこまで届くかの検査

手順
1. python3 -m http.server 8080 で配信して /tests/probe/translate-frames.html を開く。
2. 右クリック →「翻訳」→ 簡体字中国語。
3. [A]〜[F] のどれが中国語になり、どれが日本語のまま残ったかを記録する。
4. 各パネルの 自前スクリプト / ePub 由来 の行も記録する（CSP がどこまで効くかの確認）。
5. いちばん下の「Translator API」欄も記録する。
6. 翻訳した状態のまま G / H / I のボタンを押し、 [G2] [H2] [I2] が訳された状態で出るか、日本語のまま出るかを見る （Edge で章送りのあと本文が原文に戻る件の切り分け）。J は [J2] と「書き直し後のスクリプト」の行も見る。

A ─ 親ドキュメント（yomikake のツールバーと同じ立場）

top-level document

[A] これは親ドキュメントに直接書かれた日本語の本文です。吾輩は猫である。名前はまだ無い。

B ─ srcdoc の iframe・sandbox なし（v2.22.1 までの yomikake 本文）

<iframe srcdoc> / 同一オリジン / sandbox 無し / CSP 無し

C ─ srcdoc の iframe・sandbox あり（現行 v2.23.x の yomikake 本文）

sandbox="allow-scripts allow-popups allow-popups-to-escape-sandbox"（不透明オリジン）

C2 ─ sandbox に allow-same-origin を足した場合（CSP なし）

sandbox="allow-scripts allow-same-origin allow-popups allow-popups-to-escape-sandbox"

C3 ─ sandbox なし ＋ nonce の CSP（提案する形の下限）

<meta http-equiv="Content-Security-Policy" content="script-src 'nonce-…'">

C4 ─ sandbox（allow-same-origin つき）＋ nonce の CSP（提案する形）

sandbox="allow-scripts allow-same-origin allow-popups allow-popups-to-escape-sandbox" + CSP

D ─ 同一オリジンの別ファイルを src= で読む iframe

<iframe src="translate-frames-child.html">

E ─ 親ドキュメント内の Shadow DOM

attachShadow({mode:'open'}) の中のテキスト

F ─ C4 と同じ条件で、縦書き＋ルビの本文（実際の見え方）

writing-mode:vertical-rl / <ruby> / 縦中横 — 翻訳後にどう崩れるかを見る

G ─ 章送りの模倣：srcdoc を入れ替える（いまの yomikake の章送り）

fr.srcdoc = 新しい文書 ＝ フレーム内で新しい文書へ「移動」する

H ─ 章送りの模倣：同じ文書のまま中身だけ差し替える

fr.contentDocument.body.innerHTML = 新しい本文 ＝ 文書は移動しない

I ─ 同じ文書に段落を足すだけ

fr.contentDocument.body.insertAdjacentHTML('beforeend', …)

J ─ 章送りの模倣：document.open() / write() / close()

文書オブジェクトは同じまま中身を書き直す（スクリプトも実行される）

集計 ─ 各フレームの中でスクリプトがどう扱われたか

iframe から postMessage で報告させた結果（翻訳の可否は上の本文で見る）
