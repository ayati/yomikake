オフラインのフォントと読み上げの検査

知りたいこと
(1) 本文 iframe（srcdoc）の中のフォント読み込みを Service Worker が拾えるか —— 拾えなければ sw.js で保存しても本文には効かない
(2) 保存したフォントが機内モードで本当に使われるか
(3) 日本語フォント 1 書体を丸ごと先読みしたときの時間と容量
(4) 読み上げの音声が端末内のものか、機内モードで声が出るか

置き場所: https://www.ayati.com/book/tests/probe/ に offline-fonts.html と offline-fonts-sw.js の 2 つを置く。 この検査専用の SW はこのフォルダだけを担当するので、yomikake 本体の SW には影響しない。

手順
  1. オンラインで開き「① SW を登録」→ ページを再読み込み → 状態欄が 制御中: はい になる
  2. 「保存を消す」→ A・B を押す（オンライン）。ログで B の行の client=about:srcdoc を確認
  3. 機内モードにして再読み込み → もう一度 A・B を押す（C はまだ押さない）
  4. B の「まだ出ていない漢字」を押す（未保存のはず）
  5. オンラインに戻して C を押す → 機内モードで再読み込み → B の「まだ出ていない漢字」をもう一度
  6. D: オンラインで音声一覧を見る → 機内モードで日本語の音声をいくつか再生
  7. 「ログをコピー」で結果を送る（端末ごとに 1 回）
